SORU:
Kullanıcıdan a, b, c ve x değerlerini alarak a*x² + b*x + c matematiksel ifadesinin sonucunu hesaplayınız.

AMAÇ:
Java'da kullanıcıdan birden fazla değer almayı, bu değerleri değişkenlerde saklamayı ve matematiksel bir ifade içerisinde kullanmayı öğrenmek.

ÇÖZÜM MANTIĞI:
İlk olarak kullanıcıdan veri almak için Scanner sınıfı import edilmiştir.

Daha sonra Scanner sınıfından scanner isimli bir nesne oluşturulmuştur.

a, b, c ve x değerlerini saklamak için int türünde değişkenler oluşturulmuştur.

Scanner'ın nextInt() metodu kullanılarak kullanıcıdan sırasıyla a, b, c ve x değerleri alınmıştır.

Alınan değerler kullanılarak a*x*x + b*x + c matematiksel işlemi gerçekleştirilmiştir.

Hesaplanan sonuç sonuc isimli değişkende tutulmuştur.

Son olarak sonuç System.out.println() kullanılarak ekrana yazdırılmıştır.

KULLANILAN YAPILAR:

* import java.util.Scanner
* Scanner sınıfı
* nextInt() metodu
* int veri tipi
* Değişkenler
* Çarpma (*) operatörü
* Toplama (+) operatörü
* System.out.println()
* scanner.close()

KODDAKİ ÖNEMLİ KISIMLAR:

a = scanner.nextInt();
b = scanner.nextInt();
c = scanner.nextInt();
x = scanner.nextInt();

Bu kodlar ile kullanıcıdan a, b, c ve x değerleri alınarak ilgili değişkenlere atanmıştır.

sonuc = a*x*x + b*x + c;

Bu ifade ile a*x² + b*x + c matematiksel işlemi gerçekleştirilmiştir.

x*x işlemi ile x değerinin karesi alınmıştır.

System.out.println("Sonuç: " + sonuc);

Hesaplanan sonuç ekrana yazdırılmıştır.

scanner.close();

Program sonunda Scanner nesnesi kapatılmıştır.

ÖRNEK ÇALIŞMA:

Kullanıcı:
2
3
4
5

Hesaplama:
2*5*5 + 3*5 + 4
= 50 + 15 + 4
= 69

Program çıktısı:
Sonuç: 69

ÖĞRENİLENLER:
Bu soruda Java'da Scanner kullanarak birden fazla veri alma, değişken kullanma ve matematiksel ifadeleri Java içerisinde hesaplama öğrenilmiştir.

SONUÇ:
Kullanıcıdan alınan a, b, c ve x değerleri kullanılarak a*x² + b*x + c ifadesinin sonucu başarılı bir şekilde hesaplanıp ekrana yazdırılmıştır.
